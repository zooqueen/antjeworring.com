# AntjeWorring.com

Personal portfolio of **Antje Worring** - Multi-disciplinary artist, designer, and metaverse architect.

## About

This website showcases my work at the intersection of art, technology, and conservation. As Director of Zoo Labs Foundation, I lead initiatives that harness emerging technologies for wildlife protection and environmental education.

## Tech Stack

- **Framework**: Next.js 15 (App Router)
- **UI**: React 19 + TypeScript
- **Styling**: Tailwind CSS
- **Animations**: Framer Motion
- **Smooth Scrolling**: Lenis

## Getting Started

### Prerequisites

- Node.js >= 20.0.0
- npm or yarn

### Installation

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
